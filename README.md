Penjelasan OOP

1. Class: Digunakan untuk membuat kelompok atau cetakan data anggota gym.
2. Object: Digunakan untuk membuat anggota gym berdasarkan class yang sudah dibuat.
3. Constructor: Digunakan untuk mengisi data awal anggota seperti nama, umur, dan ID.
4. Inheritance: Digunakan agar class Regular dan Premium bisa mewarisi fitur dari class Membership.
5. Encapsulation: Digunakan untuk melindungi data anggota agar tidak diubah sembarangan.
6. Polymorphism: Digunakan agar setiap paket membership memiliki perhitungan harga yang berbeda.
7. Abstraction: Digunakan sebagai dasar pembuatan jenis paket membership.
8. Getter dan Setter: Digunakan untuk mengambil dan mengubah data anggota.
9. Class Method: Digunakan untuk menghitung jumlah seluruh anggota.
10. Static Method: Digunakan untuk memeriksa umur calon anggota.
